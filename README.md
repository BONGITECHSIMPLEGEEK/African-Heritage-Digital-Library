# African Heritage Digital Library

A React + Vite homepage created from the assignment brief and the supplied design.

## Features
- Responsive homepage matching the green, gold, cream and black visual style
- Search functionality
- Collection browsing
- Resource filtering by collection and format
- Five sample resources with metadata
- Collection browse page with filters
- Individual resource detail pages with metadata records
- Breadcrumb navigation and back-to-collection links
- Mobile navigation
- UI principles: simplicity, consistency, visibility and feedback

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite address shown in the terminal.

## Build for deployment

```bash
npm run build
```

The production files will be generated in `dist/`.
